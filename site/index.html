      How it works

      A crawler reads each platform's public event data every 6 hours, keeps Bay Area events about hackathons, startups, investors and campuses, and merges the same event listed on several sites. A web and social sweep adds deadlines and announcements that never reach an event platform.

      What the band means

      Entry rules come straight from the organizer's page: Luma's approval setting, YC's application deadline, Devpost registration, sold-out and waitlist flags. Hosts can change them, so check the event page before you go.

      Watching

      Events hosted by tracked VCs, schools, labs, community hubs and people get a blue tag. Hosts who keep running relevant events are picked up automatically and followed on the next crawl.
